# Apply a recentering model to new data

Apply a recentering model to new data

## Usage

``` r
# S3 method for class 'recenter'
predict(object, newdata, ...)
```

## Arguments

- object:

  A `recenter` object.

- newdata:

  Numeric matrix with the same number of channels.

- ...:

  Unused.

## Value

Recentered data matrix.
